# JS Lab — 10 JavaScript Projects

A static landing page that links to all ten projects in this repository.

## Deploy

This is a static website; no build step or backend is required.

### Netlify / Vercel
- Import the repository.
- Set the project root to the folder containing this `index.html` (the `10 JS projects` folder if you keep the archive's outer folder).
- Leave the build command empty.
- Set the publish/output directory to `.`.

### GitHub Pages
- Place the contents of `10 JS projects` at the repository root (or configure Pages to publish that folder if your setup supports it).
- Ensure `index.html` is at the published root.
